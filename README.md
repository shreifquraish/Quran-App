# القرآن الكريم

### مصحف عربي متكامل للقراءة والاستماع والتدبر

## عن المشروع

القرآن الكريم مشروع يهدف إلى تقديم أدوات المسلم اليومية داخل تطبيق واحد، بواجهة عربية كاملة واتجاه كتابة من اليمين إلى اليسار. صُممت المزايا لتكون عملية في الاستخدام اليومي، مع حفظ البيانات والإعدادات محليًا وتقليل الاعتماد على الاتصال بالإنترنت.

> الإصدار الحالي: `1.1.2+6`  
> حالة المشروع: تطوير نشط للاستخدام الخاص.

## المزايا الرئيسية

| المجال | المزايا |
| --- | --- |
| **المصحف** | قراءة السور والصفحات، متابعة آخر موضع قراءة، والتنقل السريع داخل المصحف. |
| **البحث والعلامات** | بحث محلي في نص القرآن، حفظ العلامات المرجعية، واستكمال القراءة من آخر موضع. |
| **التفسير** | عرض التفاسير واختيار السورة وقراءة تفسيرها مع التخزين المحلي عند توفر البيانات. |
| **الاستماع** | تشغيل التلاوات، تنزيل السور، وإدارة المحتوى الصوتي دون اتصال. |
| **الإذاعة** | الاستماع إلى إذاعات القرآن والمحطات الصوتية المتاحة داخل التطبيق. |
| **الصلاة والأذان** | حساب المواقيت محليًا، جدولة الأذان، وتشغيل الأذكار الصوتية الدورية. |
| **القبلة والموقع** | اختيار المدينة، استخدام الموقع عند الحاجة، وتحديد اتجاه القبلة بالبوصلة. |
| **الأذكار والأدعية** | أذكار الصباح والمساء، أدعية الأنبياء، والصلاة على النبي ﷺ. |
| **أدوات إضافية** | ورد يومي، تقويم هجري، وقواعد مبسطة للتجويد. |
| **التجربة** | واجهة عربية RTL، وضع فاتح وداكن، وتخزين محلي للبيانات والإعدادات. |

## الأذان والأذكار الصوتية

### مواقيت الصلاة

- حساب المواقيت محليًا باستخدام [Adhan Dart](https://pub.dev/packages/adhan_dart) وطريقة الهيئة المصرية.
- اختيار المحافظة أو المدينة من داخل التطبيق.
- حفظ المواقيت محليًا لتمكين الجدولة دون اتصال.
- جدولة الأذان للصلاة المفعّلة عبر Android AlarmManager.
- تشغيل ملف الأذان من خلال المشغل الأصلي في Android.
- دعم الإشعارات والمنبّه الدقيق عند توفر الصلاحيات المطلوبة.

### الصلاة على النبي ﷺ

تعمل الأذكار الصوتية الدورية بالتناوب كل نصف ساعة:

| الوقت | الملف | المحتوى |
| --- | --- | --- |
| الدقيقة `00` | `صلي علي محمد.mp3` | صلِّ على محمد ﷺ |
| الدقيقة `30` | `لا اله الا الله.mp3` | لا إله إلا الله |

يرفع التطبيق مستوى صوت المنبّه والوسائط إلى أعلى مستوى متاح في Android قبل تشغيل الذكر. وقد تمنع بعض الأجهزة أو أوضاع النظام رفع الصوت تلقائيًا لأسباب أمنية أو بسبب إعدادات الشركة المصنّعة.

## المتطلبات

- Flutter SDK متوافق مع Dart `>=3.4.4 <4.0.0`.
- Android SDK وAndroid Studio لبناء نسخة Android.
- جهاز Android أو محاكي للاختبار.
- اتصال بالإنترنت في الإعداد الأول لتحميل البيانات أو التلاوات الخارجية عند الحاجة.

## التشغيل محليًا

```bash
git clone <repository-url>
cd quran

flutter run
```

```bash

```


## أهم الاعتمادات

- `qcf_quran_lite`: عرض بيانات المصحف.
- `adhan_dart`: حساب مواقيت الصلاة.
- `just_audio`: تشغيل الملفات الصوتية.
- `flutter_local_notifications`: الإشعارات والصلاحيات.
- `provider`: إدارة حالة التطبيق.
- `sqflite` و`shared_preferences`: التخزين المحلي وحفظ الإعدادات.
- `geolocator` و`flutter_compass`: الموقع واتجاه القبلة.
- `timezone` و`workmanager`: الجدولة والمهام الخلفية.
- `dio` و`http`: تحميل البيانات والتعامل مع الخدمات الخارجية.

## الملفات الصوتية

الملفات المحلية الخاصة بالأذكار:

```text
assets/audio/صلي علي محمد.mp3
assets/audio/لا اله الا الله.mp3
```

ملف الأذان المستخدم في Android:

```text
android/app/src/main/res/raw/adhan.mp3
```

عند إضافة ملف صوتي جديد:

1. ضعه في المجلد المناسب.
2. تأكد من إدراجه في `pubspec.yaml` إذا كان ضمن أصول Flutter.
3. نفّذ `flutter pub get`.
4. أعد تشغيل التطبيق أو ابنِ نسخة جديدة.

## الصلاحيات وإعدادات Android

قد يحتاج التطبيق إلى الصلاحيات التالية بحسب الميزة المستخدمة:

- الإشعارات.
- المنبّهات الدقيقة.
- الموقع لحساب المواقيت أو تحديد القبلة.
- العمل في الخلفية وجدولة التنبيهات.

لضمان وصول الأذان والأذكار في وقتها، اسمح بالإشعارات والمنبّهات الدقيقة، وأوقف تقييد البطارية للتطبيق إذا كان نظام الهاتف يمنع المهام الخلفية.

## استكشاف المشكلات

### الأذان لا يعمل في موعده

1. تأكد من تفعيل الصلاة المطلوبة ومراجعة المدينة أو المحافظة.
2. اسمح بالإشعارات والمنبّه الدقيق.
3. عطّل تقييد البطارية للتطبيق.
4. افتح التطبيق مرة واحدة بعد التثبيت أو تغيير الموقع.
5. تأكد من وجود `adhan.mp3` داخل `android/app/src/main/res/raw/`.
6. راجع مستوى صوت المنبّه والوسائط في إعدادات الهاتف.

### الأذكار الصوتية لا تعمل

1. تأكد من وجود الملفين داخل `assets/audio/`.
2. نفّذ `flutter pub get` ثم أعد تشغيل التطبيق.
3. راجع مستوى صوت المنبّه والوسائط.
4. تحقق من عدم تفعيل وضع الصامت أو عدم الإزعاج بطريقة تمنع الصوت.
